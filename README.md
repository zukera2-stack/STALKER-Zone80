# STALKER Zone80 — Arma 3

Проект карты Чернобыльской зоны отчуждения с реальной географией и игровым слоем S.T.A.L.K.E.R.

**Статус:** проектирование и аудит. Полная карта не сгенерирована. Целевые параметры и план работ будут оформлены в отдельной рабочей ветке.

Цель: воспроизводимая подготовка геоданных и размещения объектов для единого мира Arma 3. Оригинальные пользовательские PBO/P3D не включаются в репозиторий и не изменяются.
