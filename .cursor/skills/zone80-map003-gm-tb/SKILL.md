# GM → GRM → Terrain Builder — производственный цикл v2.0
Прочитай zone80-luna-autonomous, arma3-tools-zone80, текущий Issue #42 и документы проекта. Исторический MAP-003 terrain-only gate не запрещает отдельно разрешённый синтетический MAP-005. Реальные данные всё ещё требуют отдельного допуска источника. Работай до нативного артефакта, не останавливайся на QC файлов.

## MAP-005 — активная цель
Сохранённый, повторно открываемый собственный MAP005_BASELINE.tv4p с импортированными слоями; проверить Buldozer только если возможно в рамках действующего допуска и без записи P:. Текущие поручения: #42 comments 7203582618, 7214028547, 7214797457. Stage001 PARTIAL, no WRP/PBO/merge/full-world. Не повторять принятый G1 Float32, G2 OFFLINE_05 и экспорт синтетического MAP005, если входы не менялись.

## Данные
Используй существующий TB_MAP005_HANDOFF и маску из reports/MAP-005; проверь наличие, хеши, синтетическое происхождение. Исходная геометрия EPSG:32636, 1920×1920 м, 64×64/30 м terrain, 480×480/4 м imagery; SW 294373.084,5698122.108. ASC corner, BPW/TFW upper-left pixel center. Не менять оригиналы. Если mapframe требует локальное начало 200000/0, создать согласованные производные копии всех слоёв и независимо проверить единый сдвиг, не выдавать его за географическую репроекцию. Допустимые samplers и размер текстур подтвердить в установленной версии; при несовместимости подготовить безопасную альтернативу в рамках допуска, не менять масштаб молча.

## GM и GRM
GM 26.2 Pro: использовать существующий проверенный global_mapper.exe и .gms; штатный batch/API, точный синтаксис. При необходимости проверить другой документированный способ запуска только если первый не запрещён. Реальное приобретение — исключительно утверждённые слои и способы GM Online Data, без внешнего downloader, обхода отказов, подмены источника или фиктивного заполнения. SRTM provenance/datum/rights unresolved; EOX real imagery access unverified. Не блокировать синтетический пилот из-за этих источников.
GRM: переиспользовать v04/CC05B–R, проверить реальное сопоставление классов маски, layers.cfg, зависимости stock-материалов и моделей, координаты. Разрешена ограниченная нативная синтетическая генерация и тестовое размещение по MAP-005; никакой реальной генерации до source/asset/coordinate gates. При блокере native приготовить проверенные конфиги и комплект; не называть ContractProbe полным gentb.

## TB — действовать, а не перечислять меню
1. Проверить принадлежность отдельного экземпляра, путь, состояние и отсутствие воздействия на пользовательский проект. Переиспользовать подтверждённый launcher WinSta0\Default только при необходимости и разрешении.
2. Проверить установленный mapframe workflow: create mapframe, настройки, samplers, processing/layers.cfg, rebuild, save; импорт terrain/satellite/mask/shapes/разрешённых объектов по фактически поддерживаемому порядку. Не делать вывод BLOCKED по disabled Save в пустом проекте: сначала выполнить prerequisites.
3. Использовать документированные CLI/API и разрешённые семантические UIA operations. Проверить контрол, IsEnabled, supported patterns, результат каждой операции. Не угадывать batch switches, не эмулировать мышь/клавиатуру. Если путь недоступен, проверить собственный совместимый сохранённый шаблон, штатное открытие, затем минимальный точный запрос владельцу. Не повторять сканирование UIA без нового основания.
4. После импорта — readback размеров, пяти асимметричных контролей высот, ориентации растра, маски/материалов, двух тестовых линий, counts/IDs, сохранение и штатное повторное открытие только своего проекта. Если возможен Buldozer — фактический визуальный тест и исправление. Если нет — точный blocker, не fake PASS.
5. Параллельно завершать независимые слои и материалы. Итоговый комплект: проект либо максимально готовые файлы импорта с manifest, exact paths, шагами и одним отчётом.
