Keep one source/version/datum per candidate. Do not combine or silently change source. Keep all outputs in unique local run directory.
## QC — independently read outputs, never modify heights
Parse ASC header and exactly 64 rows of 64 numbers; verify 4096 finite valid elevations, no sentinel/NaN/Inf; xllcorner/yllcorner and cellsize above, north-first order. Read GeoTIFF metadata/data and PRJ, verify CRS, 64x64, identical footprint/cell centers/units, and all 4096 valid; compare ASC/TIFF cell-by-cell within documented export precision (report tolerance and max delta, don't relax silently). Record min/max, five prior control positions and actual new values, check against loaded GM source at matching positions with explicit sampling method; old values are diagnostic not universal truth. Explain any source-driven delta. Retain evidence of source coverage. Exit 0 alone is insufficient. If gate fails, correct actual input/export issue and rerun bounded loop; never replace missing heights. Record diagnostic versus accepted source.
