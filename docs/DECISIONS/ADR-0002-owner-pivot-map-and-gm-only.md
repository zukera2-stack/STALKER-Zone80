# ADR-0002 — переход к карте и Global Mapper как единственному генератору высот

**Status:** current owner directive (2026-11-24), документ оформлен после аудита. **Относится к практическому пилоту MAP-001/002/003, не утверждает Stage 002.** Ранее `ADR-0001` остаётся проектной гипотезой единого мира.

## Контекст

Серия TB-DEFAULT / TB-UIA создала стабильную диагностику, но 60-минутный SOAK остановился на 50/120 с `CAUSE_UNKNOWN`. Возврат к общим тестам перестал помогать изготовлению карты. MAP-002 дал реальный GM26 локальный экспорт `60×62`, однако входную географическую область выбрали до целевой квадратной сетки, что дало 253 NoData. После облачного GRID-FIRST эксперимента владелец отдельно уточнил, что **готовые высоты должен формировать именно установленный Global Mapper**, а ChatGPT — давать географические параметры.

## Решения владельца (порядок отмены)

1. **Приоритет — реальная карта, не бесконечные тесты.** Новые общие UIA/SOAK по умолчанию запрещены; короткая узкая проверка допускается лишь при конкретном препятствии карты. Stage 001 остаётся PARTIAL. Оставить все прошлые реальные результаты как историю, не оформлять полный SOAK PASS.
2. **Не размещать здания и сооружения в игровом мире.** Контуры из OSM и подтверждённые атрибуты сохранять в отдельном каталоге для будущего мода зданий Припяти; 3D-модели пока не генерировать. Дорожные линии и рельеф — отдельный рабочий слой. Фото/Google 360 — только ссылочная/лицензионно корректная справочная база.
3. **Использовать Global Mapper 26.2 Pro, 64-bit**, а не версии 27 и не самодельную замену. По фактическому Windows-отчёту пакетный GM экспорт уже сработал (`exit 0`), но это не доказательство наличия каждого онлайн-источника и не равно TB-импорту.
4. **Сначала целевая игровая сетка, потом геоданные.** Для текущего пилота `64×64×30м` с конкретным UTM36N origin; не принимать случайную `60×62` сетку и `-9999` как готовый heightmap.
5. **Последнее уточнение — высоты только из Global Mapper.** ChatGPT выдаёт **задание по точным координатам, источнику и тайлам**. Локальная Cursor/Луна загружает DEM/DSM внутри Global Mapper (встроенный Online Data или легально полученный файл, открытый в GM) и **сама GM экспортирует ASC/GeoTIFF**. Не запускать новых Python/GDAL/GitHub Actions пайплайнов получения и генерации высот, не выдавать ранее сгенерированные облачные растр-файлы за текущий результат. Историческая облачная проверка [PR #43](https://github.com/zukera2-stack/STALKER-Zone80/pull/43) закрыта без merge как `SUPERSEDED`. Старые данные/логи сохраняются для аудита.
6. **Один terrain-only импорт в Terrain Builder** допускается лишь в полностью отдельный пустой project-owned sandbox без какого-либо риска для пользовательского рабочего проекта. Без зданий, без WRP/PBO/Binarize, без P:, без автоматического merge и Stage 002.
7. **Issue-first:** задачи Cursor оформляются в GitHub Issues с конкретным base SHA/входом/выходом/STOP/evidence; ChatGPT даёт ссылку вместо повторной длинной инструкции в чате.

## Текущие конкретные координаты (не production extent)

Тайл **N51 E030** (географический 1° × 1° квадрат N 51–52°, E 30–31°). Copernicus GLO-30 identifier `Copernicus_DSM_COG_10_N51_00_E030_00_DEM`; SRTM `N51E030` как альтернативный источник только после явной фиксации фактически выбранного слоя. Целевая UTM36N `EPSG:32636`: **64×64 ×30м**, нижний левый `E=294373.084, N=5698122.108`; верхний правый `E=296293.084, N=5700042.108`. Эти значения — **пилот**, а не утверждение CRS/размеров всего мира. [Полная таблица углов](../map/MAP_003_GM26_TILES.md).

## Следствия и исключения

- Код `tools/map001/fetch_public_inputs.py`, GIS/cloud artifacts, старые GMS/PR остаются в истории как воспроизводимое знание; **не удалять их и не смешивать** с источником актуального нового ASC.
- [PR #44](https://github.com/zukera2-stack/STALKER-Zone80/pull/44) является актуальной постановкой координат; [Issue #42](https://github.com/zukera2-stack/STALKER-Zone80/issues/42) — единственная активная исполняемая MAP-003 задача. [Issue #35](https://github.com/zukera2-stack/STALKER-Zone80/issues/35) — эпик; [Issue #39](https://github.com/zukera2-stack/STALKER-Zone80/issues/39) выполнен по старому этапу. Не порождать параллельные задания на то же самое.
- `main` содержит меньшую часть изменений (merged PR #1, #7, #8); внедрение этого ADR и связанных текущих документов в `main` требует отдельной приёмки PR.
- Изменить этот курс можно только новым **явным решением владельца**. Тогда добавить датированный ADR/дополнение, изменить активную Issue, матрицу и `PROJECT_STATE.yaml` одновременно.

## Отклонённые на текущий этап альтернативы

- Ещё один SOAK-60 ради тестирования среды.
- GIS экспорт из заранее вычисленного облачного ASC вместо исходного высотного слоя в Global Mapper.
- Смешивание современных OSM контуров и Google панорам с доказанной историей 1986 года.
- Генерация зданий до анализа каталога; расстановка моделей, TML/CSV placement, WRP/PBO.
- Запуск полного мира или выбор финального CRS из результатов теста на 1,92 км.
