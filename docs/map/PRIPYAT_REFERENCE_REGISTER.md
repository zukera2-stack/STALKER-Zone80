## Отдельный исторический источник

[Center for Urban History — Prypyat collection](https://www.lvivcenter.org/en/updates/prypyat-collection-2/) — коллекция материалов 1970–1986 о строительстве и жизни города и ЧАЭС из собрания краеведческого музея Славутича и ЧАЭС. Перспективный источник для проверки прежнего вида и планировки. Лицензия каждого отдельного снимка и связь с конкретным зданием не проверены — только ссылка, не копировать. Современные OSM и фотографии после 1986 года не подтверждают историческое состояние. Эпоха игрового мира не утверждена.

Продолжение: по одной выбранной записи каждой геометрической группы искать и проверять планы и фасады, документировать источник, дату, лицензию, автора, степень соответствия объекту. Не назначать строительные серии по одной похожей форме. См. [PRIPYAT_DIGITAL_GEOCATALOG.md](PRIPYAT_DIGITAL_GEOCATALOG.md).
