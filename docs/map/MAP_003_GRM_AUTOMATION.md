## Масштабирование
Один мир 81920 м, 4096*20 м; 8×8 логических секторов 10240 м (512*20). Секторы — задания предобработки, НЕ 64 WRP. Параметры центра/границ/CRS не утверждены. После пилота нужны 2 соседних сектора, halo по радиусу объектов/алгоритмов, единый origin, стабильные source IDs, deterministic seed/ownership, отсутствие дублей и швов. GRM штатное совпадение секторов не доказано. При 4м/px полный квадрат 20480² пикселей против 2560² в секторе; один RGBA буфер ~1.56 GiB против 25 MiB, не оценка общего RAM. Измерять peak working set, время, cache/disk, повторяемость.
