# MAP-003 — точные координаты и тайл для Global Mapper 26.2 Pro

**Решение владельца:** высоты получать и экспортировать **на локальном компьютере в Global Mapper 26.2 Pro**. ChatGPT передаёт только географическое задание. Не запускать Python/GDAL/GitHub Actions для формирования новых ASC/GeoTIFF и не брать подготовленные ранее ChatGPT растр-артефакты как готовую высотную карту.

## Правильный географический тайл высот

**Один тайл N51 E030**: охват **51°–52° N, 30°–31° E**. Примыкающие географические тайлы для этого маленького квадрата **не требуются**.

- Copernicus GLO-30 Public: **Copernicus_DSM_COG_10_N51_00_E030_00_DEM**. Имя реального 1° тайла, не утверждение, что источник встроен в онлайн-каталог версии 26.2.
- SRTM (запасной вариант, если выбран именно этот набор): **N51E030.hgt**. Указать фактическое разрешение источника (1 или 3 угловые секунды), не смешивать результаты с Copernicus.
- Онлайн-слои Global Mapper могут выдавать не физический HGT/COG-тайл, а данные потоком. При использовании **Online Data** инструмент сам загружает необходимые части в пределах заданных координат; имя N51E030 здесь географический идентификатор, а не обязательный файл в интерфейсе.

## Только локальная задача для Cursor/Луны

1. В Global Mapper Pro 26.2 (64-bit) открыть **Online Data**, выбрать реально доступный слой **Elevation/Terrain**. Если Copernicus есть среди доступных слоёв — использовать его; если нет — использовать законно доступный GLO-30 файл в Global Mapper либо SRTM с маркировкой источника. Не предполагать поддержку конкретного слоя/лицензии без проверки.
2. В Global Mapper выбрать проект **EPSG:32636** и ограничить экспорт **точным квадратом** из таблицы, **64×64 / 30м**; соблюдать положение центра пикселя. Источник загружать с достаточным перекрытием, чтобы область была заполнена.
3. Штатным экспортом Global Mapper получить ASC/GeoTIFF только в **новый** локальный каталог reports/MAP-003. Ни Python, ни GitHub Actions, ни скачивание заранее сгенерированных ChatGPT файлов высот.
4. Проверить **64×64**, **0 пропусков высот**, единицы в метрах, полную геопривязку, 5 реальных контрольных точек и происхождение/датум высот. Если есть NoData — **STOP**, получить исходное покрытие в Global Mapper, не заменять отсутствующие значения нулями или придуманными высотами.
5. В GitHub публиковать **только технический отчёт и описание источников**, реальные исходные DEM и производные ASC/GeoTIFF оставлять локально. Никаких зданий/сооружений на карте. Отдельный импорт только рельефа в Terrain Builder разрешён лишь при безопасной изоляции пользовательского проекта. Не merge, не WRP/PBO, не Stage 002.
