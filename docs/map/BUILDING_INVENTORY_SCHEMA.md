# BUILDING-INVENTORY — геокаталог зданий Припяти для будущего мода

**Текущий этап:** MAP-001 / Issue #35. **Геоданные собираем, здания и сооружения в карту Terrain Builder/Arma НЕ размещаем. 3D-модели НЕ создаём.** Отдельный будущий проект — мод зданий Припяти; текущая задача лишь подготовить проверяемое техническое задание на модели.

## Источники и граница между фактами и гипотезами

1. Геометрия из доступных законных GIS источников (например, OSM при соблюдении ODbL): сохранять неизменяемый исходный `source_id`, дату снимка/версии, лицензию, геометрию WGS84, измеренную/рассчитанную площадь и размеры. Уровень достоверности у каждого поля отдельный.
2. Фотографии/360 — **вторая независимая сущность**. Позиция фотографа не равна местоположению сфотографированного здания; соответствие фото конкретной постройке отмечать как `confirmed`, `probable` или `unverified`. Фото 2020-х не доказывает состояние здания в 1986 году.
3. У Google Maps/Street View разрешено сохранять **исходную ссылку на просмотр панорамы**, название/атрибуцию, дату (если она видима и подтверждена) и степень совпадения — без массовой загрузки, скриншотов, извлечения изображений, tracing/digitizing, заимствования геометрии и автоматического получения 3D-моделей из Google. Наличие панорамы в Припяти необходимо **проверять для конкретного объекта**; не считать Street View покрытие города гарантированным. Собственная 360-панорама или свободно лицензированная фотография — отдельная запись с точными условиями использования.
4. Wikimedia Commons: изображения можно копировать для работы **только после проверки лицензии конкретного файла, автора и условий атрибуции/ShareAlike**. Сохранение исходных материалов, на которые права ещё не подтверждены, в публичном Git запрещено. При лицензионной неопределённости оставить URL и статус `UNKNOWN`; **не скачивать**.
5. Никакого переноса моделей, картинок Google, чужих P3D/PBO и приватных локальных каталогов в публичный Git.

## Запись одного объекта

Структурированный GeoJSON Feature (или локальная GeoPackage с экспортом в GeoJSON для проверенных метаданных) хранится в игнорируемом `reports/MAP-001/<run-id>/building_inventory.geojson`. **В Git только схема, код и агрегированная обезличенная статистика, если это допускается лицензией источника.**

| Поле | Содержание | Если неизвестно |
|---|---|---|
| `building_id` | Стабильный идентификатор, производный от `source_dataset/source_id`, без переименования при повторном экспорте | Не выдумывать |
| `source_dataset, source_id, source_url, source_date, retrieved_utc, license` | Прослеживаемость геометрии, дата снимка и условия | `null` + `review_status=unverified` |
| `geometry` | `Polygon`/`MultiPolygon` WGS84, `EPSG:4326`; геометрия не из Google/Street View | `null`, не рисовать фиктивный дом |
| `centroid_lonlat` | Вычисленная опорная точка геометрии | `null` |
| `footprint_area_m2, bbox_length_m, bbox_width_m, perimeter_m` | Вычисляемые размеры в явно указанном временном метрическом CRS; ширина/длина ориентированного прямоугольника vs осевой bbox — указать метод | `null` |
| `orientation_deg, shape_class` | Угол длинной оси и условный тип формы (прямоугольная, Г-, П-, сложная и пр.); это предварительная классификация | `null` |
| `building_class, function, levels, height_m, roof_form, construction_material` | Тип, назначение, этажи, высота, крыша, материал — **только подтверждённые атрибуты** | `null` |
| `historical_state, valid_time, date_confidence` | Дата/эпоха: современное состояние не равно советскому | `unknown` |
| `photo_refs` | Массив объектов `url, platform, author, license, photo_date, photographer_location, subject_match, view_direction, reuse_permission, notes`; для Google **только URL и атрибуция**, файл не скачивать | `[]` |
| `measurement_confidence, building_type_confidence, photo_match_confidence` | `high/medium/low/unknown`, независимая шкала | `unknown` |
| `reference_status, model_family_candidate, review_notes` | Состояние ручной проверки, предварительная группа будущей 3D-модели, не готовая модель | `unreviewed`, `null` |

**Пример чисто структурный, без выдуманного объекта:**

```json
{
  "type": "Feature",
  "geometry": null,
  "properties": {
    "building_id": null,
    "source_dataset": null,
    "source_id": null,
    "source_url": null,
    "source_date": null,
    "license": null,
    "footprint_area_m2": null,
    "bbox_length_m": null,
    "bbox_width_m": null,
    "levels": null,
    "height_m": null,
    "building_class": null,
    "historical_state": "unknown",
    "photo_refs": [],
    "model_family_candidate": null,
    "reference_status": "unreviewed"
  }
}
```

## Global Mapper 26.2 Pro (64-bit) в каталоге

Использовать **установленный у владельца Global Mapper 26.2 Pro, 64-bit** для просмотра и проверки исходных векторных контуров, координат и размеров, а также малого изолированного GIS-экспорта. Перед утверждениями о форматах и автоматизации подтвердить функции установленной версии; не предполагать функциональность v27. Первичные данные OSM/других поставщиков и лицензия задаются независимо от программы. Каталог геометрий сохранять отдельно от рельефа/дорог; ни одно здание не размещать в Terrain Builder/Arma.

## Контроль качества

- У каждого полигона геометрия валидна, WGS84 координаты/ось подтверждены, `source_id` уникален, нет дублей при повторах и на границе участка. Если OSM не содержит контуров — фиксировать **missing**, не компенсировать синтетическими домами.
- Не считать атрибут `levels` доказанным по площади/теням или видом фасада без достоверного источника. Отдельно `verified`, `inferred`, `unknown` для каждого измерения.
- Не принимать фотографии из поисковой выдачи автоматически как фото конкретного адреса; контролировать авторство, ориентир, угол и соответствие объекту.
- Агрегация для мода: общее число объектов, уникальные группы `building_class + levels + shape_class + bbox dimensions bands`, повторяемость семейств, объекты без фото, неизвестная высота/этажность и кандидаты на **уникальные** модели. Никаких автоматически созданных P3D/3D-моделей.
- Отдельный маленький каталог **road_lines** и реальная карта высот идут в MAP-001, но **building_inventory остаётся только геоданными**, не конвертируется в Arma object placement/CSV/TML и не загружается в TB.

## Ожидаемый результат

Небольшой реальный DEM/дороги/preview (без визуализированных зданий в редакторе), каталог геоконтуров с явными неизвестными полями, проверенные URL на 360/фотографии при наличии, и краткая аналитика **сколько различных типов моделей может понадобиться**. Сравнение семейств позже, после накопления нескольких кварталов и ручного решения владельца. Результат считать **инвентаризацией, не созданным модом**.
