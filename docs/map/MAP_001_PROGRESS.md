## Выполнено в Global Mapper Pro 26.2

После ручного открытия Global Mapper владельцем оба пакетных экспорта выполнены из PowerShell без взаимодействия с открытым окном. `ProcessStartInfo.UseShellExecute=false` и один аргумент с путём к GMS. Оба процесса exit 0; журналы идентифицируют Global Mapper Pro v26.2 (b110625), 64-bit. Предыдущий отказ сохранён выше для истории.

1. Исходный ASC в EPSG:4326: 60 × 58, 3480 значений, 105–137,0315 м, NoData отсутствует. SHA-256 `9574982D3DE3058C08427F2D2442FF11C47B91F2A352A714F7CFD4A6E7D1587A`.
2. Второй GMS установил `LOAD_PROJECTION PROJ="EPSG:32636"` и экспортировал ASC и GeoTIFF с `SPATIAL_RES=30,30 ELEV_UNITS=METERS`. Журнал подтвердил UTM 36N WGS84. Проекция выбрана для пилота. Вертикаль остаётся EGM2008 по метаданным Copernicus. Вертикальное преобразование не задавалось.

Метрические выходы — **60 × 62**, шаг **30 м**, внешний нижний левый угол **294433,084 E / 5698152,108 N**. PRJ указывает метры и UTM 36N. GeoTIFF GeoKey 3072 = 32636. NoData остаётся в выходе после репроекции. GeoTIFF проверен по заголовку и привязке; побайтовое сравнение высот двух форматов не выполнялось.
