# MAP-001 — кандидатный участок Припяти

> **КАНДИДАТНЫЙ ОХВАТ / исторический документ.** Нижеследующие строки «HEAD не дошёл до HTTP» и «Исходники не получены» фиксируют **первоначальную Windows попытку**, после которой данные были получены через GitHub Actions (архивно) и позже выполнен реальный GIS экспорт в Global Mapper Pro 26.2 ([PR #41](https://github.com/zukera2-stack/STALKER-Zone80/pull/41)). **Текущий** MAP-003 источник высот загружается внутри локального GM26 по тайлу **N51 E030**. Для точной **64×64×30м** сетки использовать **не** прежний примерный bbox, а [MAP_003_GM26_TILES](MAP_003_GM26_TILES.md). Производственный 81,92км мир и его CRS ещё не утверждены.

**Кандидат, 24 ноября 2026 г.** Прямоугольник в WGS84, порядок запад, юг, восток, север: **30.045, 51.398, 30.070, 51.414**. Размер приблизительно 1,74 × 1,78 км. Дворец культуры «Энергетик» на центральной площади внутри участка (51,406750 N, 30,056667 E). Bbox ограничивает только пилот. EPSG:32636 — кандидат для временного метрического QC, производственная CRS и эпоха остаются открытыми. [Ориентир](https://en.wikipedia.org/wiki/Palace_of_Culture_Energetik).
