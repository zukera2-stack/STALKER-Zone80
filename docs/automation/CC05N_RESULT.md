## Scope and dependencies
Native FenceGenerator uses ConditionEvaluator and FencesData; FencesBuilder reads OSM barrier types wall/fence/hedge without road or elevation checks. OrientedObjectsGenerator uses ConditionEvaluator and OrientedObjectData, and ProceduralStreetLampsData when lamp definitions exist. OrientedObjectBuilder uses RoadsData; ProceduralStreetLampsBuilder uses explicit lamps, roads, rails and categories. Actual v03 retains two conditional explicit lamp definitions, but all nine road profiles have ProceduralStreetLamps=None and HasSideWalks=false, and Sidewalks is empty. Thus automatic lamps/sidewalks disabled, not all lamps removed. TreeRowsBuilder reads explicit natural=tree_row; native TreeRowsGenerator uses its configured row definition, never applied here to ordinary forest. SidewalksGenerator returns empty before requesting SidewalksData; full sidewalk builder not tested. Ten native allowed data types, only final synthetic ElevationData seeded. Missing RoadsData and forbidden RawElevationData/ElevationWithLakesData/ElevationOutOfBoundsData refused. No stock BuildingGenerator or generic replacement of ZPB buildings. Other catalog layers including orchard/vineyard, default areas, rocks/scree and lake surface not newly tested; do not claim entire GRM closure.
