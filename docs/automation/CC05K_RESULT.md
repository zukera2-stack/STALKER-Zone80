## Scope and dependency review
Native RoadsBuilder parses/merges/filters OSM ways without heights. RailwaysBuilder depends on RoadsData and resolves explicitly tagged level crossings with configured rail compositions. BridgeGenerator reads final ElevationData and RoadsData; RailwayGenerator reads RailwaysData, outputs relative placement. Original ElevationBuilder separately consumes ElevationWithLakesData and adjusts roads, rails, watercourses and lake constraints; it remains forbidden. The guard allows only RoadsData and RailwaysData, final synthetic ElevationData is preseeded, no other cached data. Missing RoadsData for railway, unseeded ElevationData, RawElevationData, ElevationWithLakesData and ElevationOutOfBoundsData refused. No entire gentb/full factory, no imagery or elevation export.

Native RoadsCompiler writes roadslib.cfg and roads.shp/shx/dbf into an explicit allowlisted in-memory filesystem (not files on disk). Native RoadsDeserializer reads them back. All 9 configured road profiles compare texture/textureEnd/material/texture width and two non-bridge road records compare ID/ORDER and endpoints within 0.02m. Native compiler handles road X shift; this is a native roundtrip, not an independent format/coordinate proof. No runtime texture or surface rendering. Normalized decoded geometry/profile fingerprint used instead of cross-process raw DBF byte comparison (date header). No export artifact with real roads.

Real geometry is not thereby proven absent. Preserve source ID lineage and audit dropped/merged roads, short bridges, pedestrian areas and unsupported tags before production. Stock rail builder handles railway=disused exactly as rail; ordinary track geometry survives but abandonment state is not preserved in output. Extend approved separate state overlay to roads/rail without changing OSM. Explicit review of short bridge handling and crossing composition dimensions needed; do not restore missing paths automatically or assume native fit. Grade/curvature, deck approaches, embankment/tunnel, drainage, terrain alignment of long tracks, physical overlap, Arma AI, game resources and sector seams NOT TESTED. Height response proves no mutation, not acceptable real road/rail grade. Global Mapper remains sole authority for real relief.
