## Sector decision candidate
Half-open split x=240 on final reviewed model points reconciles per-layer record multiset exactly, no lost records within that fixture. Separate experiment with polygons clipped before running same native ForestGenerator produces 738 records versus 737 when whole polygons used; only 216 exact distinct CSV records common. Source AreaDefinition seeds random using polygon centroid. Clipping changes input geometry/seed, and native FillAreaBase uses parallel scheduling; do not assume independently clipped sectors match. Proposed architecture: retain full connected source polygon geometry and stable generation task identity, resolve interacting polygons as groups, then distribute final records by sector ownership. This is a measured design constraint and candidate approach, not proof of full-world scalability, halo equivalence, dirty set or worker integration.
