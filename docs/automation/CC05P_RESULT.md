## Job and catalog contract
Native child accepts exactly config, cache and job JSON file arguments. Closed nine-field schema: schema_version=1, scope=synthetic_review_only, fixture=cc05o-inline-480m-v1, road_state in abandoned/operational/unknown, height_delta_m in 0/100, exact config/cache/OSM SHA256, export=false. Reject extra/missing/duplicate fields, invalid types/values, malformed or >8192-byte job. No arbitrary command, layer activation, output path or real coordinates. Actual input files and generated fixed inline OSM XML checked against exact hashes (OSM d20dbe01972c981946bf17254f94a8180cbbd7c867e9741d88a91301fa0a222c); recheck source bytes before result. Job ID canonicalized independently of JSON field ordering/whitespace. Fixed fixture geometry and two synthetic grids only. This is not an authentication/security boundary; local input paths are trusted CLI arguments, not an adversarial filesystem policy. Worker must separately pin executable/dependencies, approval, expiry, limits and attempts.

Native catalog exact 27 names checked against explicit dispositions before generation. 12 enabled_synthetic (all emitting CC05O layers), SidewalksGenerator disabled_verified_empty invoked only to assert zero, BuildingGenerator disabled_zpb (no generic historical building substitute). 13 pending_review: seven default area generators (agricultural/commercial/industrial/military/residential/retail and DefaultAreas), LakeSurfaceGenerator, OrchardGenerator, RocksGenerator, ScreeGenerator, VineyardsGenerator, WatercourseRadialGenerator. Pending does not mean forever disabled. No new production-layer approval or full native IdMap. Catalog classification is implementer choice for bounded next integration, not owner acceptance of permanent omissions.

## Result contract
Exactly one RESULT_JSON line on successful child run, with catalog, input and output digests, total/held/left/right counts, source review, and per-record logical ID, transform payload and content SHA, layer, review reason and sector. ID hashes fixture name plus existing non-height layer/model/position/orientation/scale/mode key; duplicate logical key rejected, not a durable source entity identifier. Content digest additionally includes elevation field and world Z. Review digest covers keys, reasons, ownership and existing source inventory/decisions. Every record explicitly has source_feature_id=null and provenance=layer_and_fixture_only; 21-way/7-tagged-node fixture inventory retained, no claimed full feature lineage. Stable IDs on same fixture/height shift do not establish stability across changed geometry/config/versions. Point-pass is not runtime approval. Independent Python verifier recomputes job/record/payload/review hashes, checks finite transforms, catalog count/status, layer membership, uniqueness and ownership reconciliation. It is a bounded validator, not an independent simulation or authenticated manifest. No durable result publication, Worker integration or physical collision proof.
