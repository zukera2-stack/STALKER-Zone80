## Конвейер
1. Sector Manager: общий origin/CRS, утверждённые границы мира, sector core + halo, stable IDs, единый snapshot. Цель 81920 м / 4096² x20 м / 8x8 логических секторов по 10240 м, не 64 WRP. Пока только MAP-003 1920 м, 64² x30 м, EPSG32636.
2. Global Mapper 26.2 Pro: единственный источник обработки и экспорта реальных высот; отдельно геопривязанные спутниковые изображения высокого качества (источник/дата/лицензия/реальное разрешение/размер/облачность и соответствие единому grid должны быть проверены). Не путать satellite imagery с диагностическими screenshots и DSM с DTM. Не подменять источники, не интерполировать отсутствующие данные. Получение imagery пока не разрешено старым elevation-only заданием; сначала source and export preflight, затем отдельное согласование источника/объёма/прав. Никакого Python/GDAL-generated terrain.
3. Config Builder/Asset Manager: reuse Zone80 v02/v03 and CC04, check 22 stock refs, mud/ice, surface/clutter, base world, dependency closure and rights. GRM pinned upstream v0.11.1 / 2aef2040836daa11a8a368bb0c7f9ecd8f405d65. Не выдавать editor-only config за production.
4. GRM: готовит географические и процедурные слои, маски поверхностей, дороги, растительность и согласованную инфраструктуру по утверждённым профилям; факты отдельно от прокси. CC05B/CC05P/Q adapter supplies GM-only heights to approved native consumers, rejects hidden elevation/satellite generation and unauthorized writes. Для GRM отдельно проверить node-aligned lattice; TB cell-centered ASC не сдвигать. Реальная интеграция NOT RUN, не разрешено запускать gentb/genwrp/genmod или размещать здания. ZPB independently owns authentic building assets.
5. Sector package: manifest with source/config/asset/script hashes and version, core/halo/CRS/origin, terrain ASC/PRJ/TIFF, satellite raster and metadata, mask/material mapping, roads, object spool with stable IDs/coordinates, separate building catalogue, preview, QC and local paths. Proposed deliverable, not actual files. Separate per-layer statuses; dependencies BLOCKED until predecessors PASS. Keep previous valid output and new attempt directory. Rebuild only affected nodes when actual dependency proof exists.
6. Assembly: verify two adjacent real sectors before batch expansion: exact common grid, height and imagery alignment, material consistency, unique ownership/no duplicates, shared roads/water/objects, overlap/halo, repeatability. Final single world assembly only after owner authorizes actual production boundaries, dependencies and later WRP/PBO. Current TB import limited to one isolated terrain-only pilot following A PASS and acceptance.
