### Одна задача — один фактический результат

- **Вход:** Issue (ссылка, цель, base SHA, инструменты, точный tile/CRS/grid, ограничения, STOP).
- **Исполнение:** Cursor/Луна на Windows делает только утверждённые действия. Каждое подтверждение — `лог/команда/время/версия/файл/SHA/снимок`; если нет — `NOT RUN` или `BLOCKED`.
- **Выход:** отчёт в том же Issue + Draft PR с минимальными изменениями и ссылками на реальную доказательную базу. Ветка/PR не означают автоматического принятия.
- **Аудит:** ChatGPT сопоставляет измерения с требованиями, явно пишет `PASS/PARTIAL/FAIL/BLOCKED/NOT RUN` по каждому gate. **Не назначать повторно уже выполненную проверку** без причины.
- **Следующее назначение:** сначала закрыть/пометить предыдущее задание и обновить матрицу/состояние, затем выдать только одну исполняемую операцию.

Срок или успех заранее не обещать, ещё ничего локально по новой задаче не выполнялось.

**Это одно интеграционное испытание, а не последовательность новых Issue и не четыре независимых разрешения.** В рамках разрешённого объёма можно самостоятельно устранить узкий реальный блокер, сохранив логи; при опасности исходным данным/текущему TB процессу — STOP только рискованной части и продолжение независимых частей. **A/B/C/D статусы различать**, частичный результат сохранять. В остальном действуют ADR-0002, запрет новых Python/GDAL heightmap, долгих SOAK, моделей/объектов в TB, P:/WRP/PBO/Arma и Stage 002 без владельца.

Читать [Issue #42](https://github.com/zukera2-stack/STALKER-Zone80/issues/42) как конкретную спецификацию для исполнителя; она имеет приоритет перед старым узким изложением ниже. **Только [Issue #42](https://github.com/zukera2-stack/STALKER-Zone80/issues/42)**: выбрать доступный в установленной GM26.2 источник высот для **N51 E030** → проверить охват → задать **фиксированную UTM сетку** 64×64×30м в [`MAP_003_GM26_TILES.md`](map/MAP_003_GM26_TILES.md) → экспортировать **в самом Global Mapper**, записать 5 точек, CRS/NoData, checksum и окно/лог (реально имеющиеся). **Не использовать готовые heightmap из облачного Python** и не считать прошлый CI артефакт решением.
