# GIS experiments

projection_probe.py requires optional pyproj and an actual owner-approved WGS84 center; it evaluates geodesic scale error and inverse residual near edges. It does NOT choose the full 81.92 km map extent, prove real footprint accuracy or approve production CRS automatically.

Global Mapper .gms batch export templates will be created **after** local installed Global Mapper 27 syntax and a small DEM have been tested. Do not add an untested supposed working script or silently substitute a map location.
