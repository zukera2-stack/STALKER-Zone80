# CC-03 Sector Manager
Python standard library. Synthetic logical coordinates only, integer millimetres, half-open outer world (north/east maximum excluded). Point anchors have one owner; segments have context only, no physical placement or clipping. The halo is a conservative bounding-box filter; 100 m in demo is a synthetic test choice, not approved production buffer. Collinear segments require review.
Run `python -m unittest -v test_sector_manager.py` from this directory. In the repository run `python demo.py --repo-root ../../..` from tools/automation/cc03 (or provide the actual repository root). Demo reads existing foundation generator and prints synthetic report; it never writes geometry or native files.
Dirty sector IDs reflect changed sector input/context/rule/generator identity. No actual Worker job submission or native execution. Not a CRS transformation or GIS seam validation. Only point and straight segment fixtures supported. State is trusted, not a security boundary.
